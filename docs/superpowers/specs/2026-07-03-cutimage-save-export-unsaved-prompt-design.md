# CutImage 保存、导出与未保存关闭提醒设计文档

## 1. 背景

当前 GUI 在“保存项目”和“导出结果”两个入口上的产物行为不一致：

1. 点击“保存项目”且未勾选“保存裁剪图”时，只会保存项目 `json` 文件。
2. 点击“导出结果”且未勾选“保存裁剪图”时，会同时导出项目 `json` 文件和最终拼接图。

这与用户对两个入口的直觉不一致：

1. “保存项目”应保存继续编辑所需的项目文件，同时也应落下一份当前最终拼接图。
2. “导出结果”更像是导出面向使用的成品，不应再额外生成项目副本。

同时，当前程序在用户裁剪后直接关闭窗口时，还缺少未保存变更提示，容易造成修改丢失。

## 2. 目标

本次改动目标如下：

1. 点击“保存项目”时，始终保存项目文件。
2. 点击“保存项目”时，以当前项目名自动新建同名文件夹，并在其中输出最终拼接图。
3. 点击“保存项目”时，仅在勾选“保存裁剪图”时在该文件夹内输出 `./cropped/`。
4. 点击“导出结果”时，仅导出最终拼接图。
5. 点击“导出结果”时，仅在勾选“保存裁剪图”时输出 `./cropped/`。
6. 点击“导出结果”时，不再在导出目录额外生成项目副本 `json`。
7. 当存在未保存修改时，关闭窗口、新建项目、打开项目之前弹出“保存 / 不保存 / 取消”提示。

## 3. 非目标

本次不处理以下内容：

1. 不改变单张裁剪图的命名方式，仍按原文件名写入。
2. 不把 `cropped/` 改为增量命名。
3. 不新增“导出项目副本”独立开关。
4. 不新增“关闭项目”菜单项。
5. 不重构图像处理算法本身。

## 4. 交互设计

### 4.1 保存项目

点击“保存项目”时：

1. 若当前项目尚未有项目文件路径，则先执行“另存项目”选择父目录。
2. 将当前项目 `json` 保存到“同名文件夹/项目文件名”路径。
3. 在该同名文件夹中导出最终拼接图。
4. 当“保存裁剪图”为勾选状态时，在该同名文件夹中导出 `./cropped/`。

当“保存裁剪图”为未勾选状态时：

1. 不生成新的 `./cropped/`。
2. 但仍然保存项目 `json` 和最终拼接图。

### 4.2 导出结果

点击“导出结果”时：

1. 保持现有“导出目录复用”逻辑。
2. 导出目录中只写最终拼接图。
3. 当“保存裁剪图”为勾选状态时，再额外写 `./cropped/`。
4. 不再在导出目录写出项目副本 `json`。

如果当前项目本身已经关联了正式项目文件路径：

1. 允许将最新项目状态继续同步写回该项目文件。
2. 这样“导出结果”不会产生新的项目副本，但也不会让界面中的最新项目配置只停留在内存里。

### 4.3 未保存关闭提醒

当存在未保存修改时，在以下时机弹窗：

1. 关闭主窗口。
2. 新建项目前。
3. 打开项目文件前。

弹窗按钮行为为：

1. `保存`：执行当前项目保存；若保存成功，再继续关闭或切换。
2. `不保存`：直接关闭或切换，不落盘当前修改。
3. `取消`：中止当前关闭或切换操作。

## 5. 实现设计

### 5.1 统一产物写出逻辑

在 `./ui/main_window.py` 中抽出统一的产物写出方法，按参数控制：

1. 是否写项目 `json`
2. 是否写最终拼接图
3. 是否写 `cropped/`
4. 目标目录来源是“项目保存对应的同名文件夹”还是“导出目录”

这样避免“保存项目”和“导出结果”各自维护一套相似但不一致的文件输出逻辑。

### 5.2 未保存状态跟踪

在主窗口中增加项目级“脏状态”字段。

以下改动会将状态标记为未保存：

1. 裁剪框拖拽修改。
2. 手动输入边界并应用。
3. 清除手动修正。
4. 图片顺序调整与恢复排序。
5. 批量处理完成后导致项目中的识别框、状态信息或拉伸高度发生变化。
6. 项目名、最终导出名、是否与项目名一致、是否保存裁剪图、全局处理参数、样式参数的变化。

以下操作会清除未保存状态：

1. 成功保存项目。
2. 成功另存项目。
3. 成功打开项目后初始载入完成。
4. 新建项目后初始载入完成。
5. 用户选择“不保存”并继续切换项目或关闭窗口时，直接丢弃当前脏状态。

### 5.3 关闭前拦截

为 Tk 主窗口注册关闭协议处理函数：

1. `WM_DELETE_WINDOW`

在关闭前统一进入未保存检查流程。

同一检查流程也复用于：

1. `new_project()`
2. `open_project()`

## 6. 验证点

完成后至少验证以下场景：

1. 点击“保存项目”且未勾选“保存裁剪图”时，生成项目 `json` 和最终拼接图。
2. 点击“保存项目”且勾选“保存裁剪图”时，额外生成 `./cropped/`。
3. 点击“导出结果”且未勾选“保存裁剪图”时，只生成最终拼接图。
4. 点击“导出结果”且勾选“保存裁剪图”时，生成最终拼接图和 `./cropped/`，但不生成项目副本 `json`。
5. 裁剪后直接关闭窗口，会弹出“保存 / 不保存 / 取消”提示。
6. 选择“保存”且保存成功后，窗口可继续关闭。
7. 选择“取消”后，窗口保持打开。
8. 打开项目或新建项目前，如当前项目有未保存修改，也会出现同样提示。

## 7. 结论

本次采用“统一产物写出逻辑 + 项目级未保存状态跟踪”的方案，让“保存项目”负责项目持久化与当前结果落盘，让“导出结果”只负责成品导出，同时补上关闭前保存提醒，减少误操作带来的结果缺失与修改丢失。
