# CutImage 圆角矩形导出功能设计说明

## 1. 背景

当前工具已经支持批量裁剪、拼接、背景切换、对齐方式切换和增量导出。现在需要进一步增强结果样式控制能力，使用户可以决定导出时使用直角矩形还是圆角矩形来呈现比色皿。

该功能的目标不是改变自动识别或手动修正时使用的裁剪框形状，而是在结果输出层为单张裁剪图和最终拼接图分别增加可配置的矩形样式。

## 2. 目标

本次新增功能需要满足以下目标：

1. 用户可以分别控制单张裁剪图的导出形状。
2. 用户可以分别控制最终拼接图的导出形状。
3. 单张裁剪图和最终拼接图都支持 `直角矩形` 与 `圆角矩形` 两种模式。
4. 圆角模式下，单张裁剪图和最终拼接图分别拥有独立的圆角半径参数。
5. 预览区能够反映当前样式设置，避免必须导出后才能看到最终效果。

## 3. 范围

### 3.1 本次范围

1. 为单张裁剪图新增样式设置：`直角矩形 / 圆角矩形`。
2. 为最终拼接图新增样式设置：`直角矩形 / 圆角矩形`。
3. 为两类结果分别新增圆角半径参数。
4. 在预览区同步显示当前样式效果。
5. 导出时根据对应设置生成实际结果图。

### 3.2 暂不纳入范围

1. 按不同图片分别设置不同圆角半径。
2. 椭圆、胶囊形、多边形等其他外形。
3. 基于透明通道的复杂图层合成编辑器。
4. 按比例模式设置圆角半径。

## 4. 总体方案

本功能采用“结果层样式控制”的实现方式，而不是改变底层裁剪框逻辑。

也就是说：

1. 自动识别仍然输出普通矩形裁剪框。
2. 手动修正仍然通过矩形框完成。
3. 在生成单张裁剪图时，根据单张输出样式决定是否应用圆角遮罩。
4. 在生成最终拼接图时，根据最终拼接样式决定是否对每个参与拼接的图块应用圆角遮罩。

这样做的优点是：

1. 不会影响现有自动检测与拖拽修正逻辑。
2. 不会增加裁剪框编辑复杂度。
3. 能够将“识别逻辑”和“显示风格”明确分层。
4. 更容易与当前预览和导出链路集成。

## 5. 功能设计

### 5.1 单张裁剪图样式

单张裁剪图新增两项设置：

1. 输出形状：`直角矩形` 或 `圆角矩形`
2. 圆角半径：像素值，仅在圆角模式下生效

行为规则如下：

1. 当设置为 `直角矩形` 时，导出的单张裁剪图保持现有矩形效果。
2. 当设置为 `圆角矩形` 时，对裁剪结果应用圆角遮罩。
3. 圆角切掉的四角区域直接显示背景色，不改变原始主体区域内容。

### 5.2 最终拼接图样式

最终拼接图新增两项设置：

1. 输出形状：`直角矩形` 或 `圆角矩形`
2. 圆角半径：像素值，仅在圆角模式下生效

行为规则如下：

1. 当设置为 `直角矩形` 时，拼接图保持当前矩形排列效果。
2. 当设置为 `圆角矩形` 时，参与拼接的每张结果图块先应用圆角遮罩，再进行拼接。
3. 拼接图中的圆角区域露出当前拼接背景色。

### 5.3 单张与最终拼接分别控制

两类设置必须完全解耦，允许出现以下组合：

1. 单张裁剪图直角，最终拼接图圆角
2. 单张裁剪图圆角，最终拼接图直角
3. 两者都直角
4. 两者都圆角，但圆角半径不同

## 6. 参数设计

建议在 `ProcessingSettings` 中新增以下字段：

1. `crop_shape_mode`
   取值：`square` / `rounded`
2. `crop_corner_radius`
   单张裁剪图圆角半径，单位像素
3. `final_shape_mode`
   取值：`square` / `rounded`
4. `final_corner_radius`
   最终拼接图圆角半径，单位像素

默认值建议如下：

1. `crop_shape_mode = square`
2. `crop_corner_radius = 18`
3. `final_shape_mode = square`
4. `final_corner_radius = 18`

## 7. 圆角规则

圆角处理规则建议统一如下：

1. 半径单位使用像素。
2. 半径最小值为 `0`。
3. 半径最大值自动限制为图片短边的一半。
4. 当半径为 `0` 时，效果等价于直角矩形。
5. 即使设置为圆角模式，只要半径被限制后等于 `0`，最终也按直角效果处理。

## 8. 预览设计

### 8.1 单张预览

当前裁剪结果预览应当反映单张裁剪图的输出样式：

1. 当单张样式为直角时，预览显示直角结果。
2. 当单张样式为圆角时，预览显示圆角结果。

### 8.2 拼接预览

拼接预览应当反映最终拼接图的输出样式：

1. 当最终拼接样式为直角时，预览显示直角拼接效果。
2. 当最终拼接样式为圆角时，预览显示圆角拼接效果。

## 9. 界面设计

建议在右侧参数区新增两个分组：

### 9.1 单张裁剪图样式

1. 形状：`直角矩形 / 圆角矩形`
2. 圆角半径：数值输入

### 9.2 最终拼接图样式

1. 形状：`直角矩形 / 圆角矩形`
2. 圆角半径：数值输入

交互规则如下：

1. 当选择 `直角矩形` 时，对应的圆角半径输入框可以禁用，或保留但不生效。
2. 当选择 `圆角矩形` 时，对应的圆角半径输入框启用。
3. 任一设置变化后，都应允许用户刷新预览查看结果。

## 10. 实现建议

建议新增一个统一的圆角处理辅助函数，接收以下输入：

1. 原始 RGB 图像
2. 形状模式
3. 圆角半径
4. 背景色

函数职责如下：

1. 如果是直角模式，直接返回原图。
2. 如果是圆角模式，构建圆角遮罩。
3. 将四角裁掉后的区域填充为背景色。
4. 返回应用样式后的结果图。

该函数可同时被单张裁剪图生成流程和最终拼接图生成流程复用。

## 11. 项目保存

项目文件需要保存新增的样式设置，确保下次打开项目时仍能恢复：

1. 单张裁剪图形状模式
2. 单张裁剪图圆角半径
3. 最终拼接图形状模式
4. 最终拼接图圆角半径

## 12. 异常与边界情况

需要明确处理以下情况：

1. 半径输入为负数
   自动夹紧到 `0`
2. 半径过大
   自动夹紧到图片短边一半
3. 极小图片
   半径自动限制，避免掏空内容区域
4. 预览与导出不一致
   必须共用同一套样式处理逻辑，避免视觉不一致

## 13. 验收标准

完成后至少满足以下标准：

1. 用户可以分别设置单张裁剪图和最终拼接图的形状模式。
2. 用户可以分别设置两类结果的圆角半径。
3. 单张预览能正确显示单张样式效果。
4. 拼接预览能正确显示最终拼接样式效果。
5. 导出的单张裁剪图能够按设置生成直角或圆角效果。
6. 导出的最终拼接图能够按设置生成直角或圆角效果。
7. 项目保存后重新打开，新增样式设置能够正确恢复。

## 14. 实施顺序

建议按以下顺序实现：

1. 扩展设置模型与项目保存结构
2. 实现统一的圆角结果处理函数
3. 接入单张裁剪图生成与单张预览
4. 接入最终拼接图生成与拼接预览
5. 补齐界面控件与测试
