# 项目文件与恢复

## 用途

本文件说明项目文件保存了什么，以及重新打开项目时程序会如何恢复状态。

## 当前保存内容

项目文件当前会保存或恢复以下信息：

1. 项目名
2. 源图片目录
3. 导出目录
4. 图片顺序
5. 各图片的裁剪框与修正状态
6. 全局处理参数与样式参数
7. 最终导出名称
8. 是否与项目名同步最终导出名称
9. 是否导出 `cropped/` 裁剪图目录

## 路径策略

当前保存逻辑会尽量把以下路径写为相对路径：

1. `source_dir`
2. `output_dir`

这样做的目标是：

1. 提高项目搬运后的可用性
2. 降低绝对路径变化带来的失效风险

## 打开项目后的恢复行为

重新打开项目时，程序当前不会只恢复表面配置，而是会继续做这些事：

1. 恢复参数、图片顺序和导出配置
2. 根据保存的裁剪框重新读取原图
3. 重建 `processed_crops` 缓存
4. 自动恢复最终拼接预览

这也是为什么打开项目后通常不需要再手动点一次“批量处理”。

## 保存项目时的额外行为

点击“保存项目”时，除了写出项目 `json` 文件外，还会：

1. 以当前项目名新建同名文件夹
2. 在该文件夹中同步输出当前最终拼接图

这属于当前项目保存链路的一部分。
