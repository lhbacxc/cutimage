# 已知限制

## 当前已知限制

1. `cropped/` 目录中的单张裁剪图仍按文件名覆盖，不采用增量命名。
2. 左侧图片列表当前还不支持直接拖拽排序。
3. 批量处理虽然已异步化，但还没有“取消处理”按钮。
4. 拼接预览本质上仍是预览图，不是最终导出图的 1:1 显示。
5. 批量处理线程当前不支持中途暂停或取消。
6. 如果后续需要“锁定拉伸高度，不再自动回到平均值”，还需要新增开关。

## 使用与维护时需要注意

1. 旧项目文件打开时需要继续兼容缺省字段。
2. 修改导出规则时，应优先更新 `./features/export.md` 作为唯一真源。
3. 修改修框交互时，应同步检查 `./features/editing.md` 是否仍准确。
4. 修改批量处理或未保存提醒时，应同步检查 `./features/ui-behavior.md`。

## 可能的后续方向

1. 为 `cropped/` 增加可选的增量命名模式。
2. 为批量处理增加取消按钮。
3. 为左侧图片列表增加拖拽排序。
4. 为拉伸模式增加“锁定统一高度”开关。
