# CutImage 项目概览

## 项目定位

CutImage 是一个本地桌面 GUI 工具，目标是批量识别图片中的有效主体区域，并输出统一样式的最终拼接图。

项目当前不是命令行脚本集合，而是围绕“可重复使用、可保存项目、可人工修正”的桌面工具来设计。

## 当前技术栈

1. `Tkinter`
2. `OpenCV`
3. `Pillow`
4. `NumPy`

## 当前主要能力

### 项目管理

1. 新建项目。
2. 打开已有项目。
3. 保存项目与另存项目。
4. 重新打开后恢复图片顺序、裁剪框、样式参数和导出配置。

### 图片处理

1. 批量读取图片。
2. 自动识别裁剪区域。
3. 支持人工拖拽修框。
4. 支持手动输入边界数值。
5. 支持点击边后用键盘做像素级微调。

### 样式控制

1. 支持纯黑或纯白背景。
2. 支持顶部对齐、居中对齐、底部对齐、上下对齐（拉伸）。
3. 支持直角矩形和圆角矩形。
4. 白底时支持可选细灰边线。

### 导出

1. 最终拼接图导出为无损 `png`。
2. 最终导出名称支持跟随项目名或自定义。
3. 最终图默认采用增量命名。
4. 可选是否导出 `cropped/` 裁剪图目录。

## 当前默认体验

新建项目时，当前默认值为：

1. 背景默认 `纯白`
2. 对齐默认 `上下对齐（拉伸）`
3. 单张裁剪图默认 `圆角矩形`
4. 最终拼接图默认 `圆角矩形`
