# 界面行为

## 用途

本文件说明批量处理、进度反馈、冲突操作禁用以及未保存提醒等界面级行为。

## 批量处理异步执行

点击“批量处理”后，当前图片处理会在后台线程执行。

GUI 主线程主要负责：

1. 刷新进度条
2. 刷新进度文本
3. 在处理完成后做界面收尾

这使得界面在处理大量图片时不再表现得像卡死。

## 处理进度反馈

当前顶部会显示：

1. 进度条
2. 进度文本，例如“正在处理 12 / 57：xxx.png”

## 处理中禁用的操作

处理过程中会临时禁用与处理链路冲突的操作，例如：

1. 新建项目
2. 打开项目
3. 保存项目
4. 另存项目
5. 批量处理
6. 导出结果
7. 拖拽裁剪框
8. 手动修正
9. 清除修正
10. 调整图片顺序

## 导出前自动触发处理

如果当前项目还没有有效处理缓存就点击“导出结果”：

1. 程序会先自动启动一轮异步批量处理
2. 处理完成后再自动继续导出

如果当前已经在处理中，则会提示先等待处理完成。

## 未保存提醒

当存在未保存修改时，以下场景会弹出保存提示：

1. 关闭主窗口
2. 新建项目前
3. 打开其他项目前

弹窗行为如下：

1. 选择“是”表示先保存，再继续当前操作
2. 选择“否”表示放弃当前未保存修改，继续当前操作
3. 选择“取消”表示中止当前操作，返回继续编辑

## 打开项目后的预览恢复

重新打开项目时，程序会根据已保存的裁剪框重建缓存，因此通常不需要再手动点击一次“批量处理”。
