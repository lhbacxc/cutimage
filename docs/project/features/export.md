# 导出规则

## 用途

本文件是当前导出行为的主说明文档。涉及导出目录、最终图命名、`cropped/` 开关和格式限制的问题，优先看这里。

## 当前导出产物

### 导出结果

点击“导出结果”时，当前会输出：

1. 导出根目录下的最终拼接图
2. 可选的 `cropped/` 裁剪图目录

当前不再额外导出项目副本 `json` 到“导出结果”目录中。

### 保存项目

点击“保存项目”时，当前会：

1. 保存当前项目文件
2. 以当前项目名新建同名文件夹
3. 在该文件夹中同步输出最终拼接图

## 最终拼接图规则

1. 最终拼接图当前只导出一张。
2. 输出格式只允许无损 `png`。
3. 导出路径模板为 `./<最终导出名>.png`。
4. 默认情况下，最终导出名跟随项目名。
5. 取消“与项目名一致”后，可以自定义最终导出名。
6. 如果自定义名称为空，仍会回退到项目名。

## 增量命名规则

当前最终拼接图默认不覆盖旧文件，而是使用增量命名。

示例：

1. `项目名.png`
2. `项目名_001.png`
3. `项目名_002.png`

## `cropped/` 目录规则

顶部工具栏当前支持“保存裁剪图”勾选框。

规则如下：

1. 勾选时，导出 `cropped/` 目录和单张裁剪图。
2. 不勾选时，本次导出不写新的 `cropped/`。
3. 取消勾选不会自动删除历史已存在的 `cropped/` 目录。
4. 同一项目重复导出时，`cropped/` 中单张裁剪图仍按文件名覆盖。

## 导出目录复用

如果项目文件中已经保存了 `output_dir`：

1. 再次点击“导出结果”时，不会重新询问导出目录。
2. 会继续写入原来的导出目录。

## 导出前自动处理

如果当前还没有有效处理缓存就点击“导出结果”：

1. 程序会先自动启动一轮异步批量处理。
2. 处理完成后再自动继续导出。
3. 如果已经在处理，则会提示先等待处理完成。
