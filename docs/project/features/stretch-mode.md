# 拉伸模式

## 用途

本文件说明“上下对齐（拉伸）”模式的当前行为，以及统一高度如何确定。

## 当前模式

对齐方式当前支持：

1. 顶部对齐
2. 居中对齐
3. 底部对齐
4. 上下对齐（拉伸）

其中“上下对齐（拉伸）”会让所有单图在最终拼接时上下齐平。

## 统一高度策略

拉伸模式下，程序当前会使用 `stretch_target_height` 作为统一高度。

所有单图会先根据这个高度做纵向拉伸或压缩，再参与最终拼接。

## 平均高度规则

当前 `stretch_target_height` 已不再主要依赖固定默认值，而是会自动回到当前有效裁剪图的平均高度。

平均高度采用四舍五入后的整数。

## 触发更新的场景

以下场景会触发平均高度重新计算：

1. 批量处理完成后
2. 手动输入边界修正后
3. 拖拽裁剪框修正后
4. 清除手动修正并重新处理后

## 当前影响

这种策略的目标是：

1. 减少拉伸模式下过度压扁或拉长
2. 让最终拼接图更贴近当前裁剪结果的整体平均尺度
