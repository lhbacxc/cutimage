# 单图修正与微调

## 用途

本文件说明用户如何修正单张图片的裁剪框，以及当前支持哪些微调方式。

## 当前修正方式

单图修正当前支持三种主要方式：

1. 在原图画布中拖拽裁剪框
2. 在右侧手动输入上下左右边界数值
3. 点击裁剪框边线后使用键盘方向键微调

## 拖拽修框

当前可以直接在原图预览区域对裁剪框进行拖拽调整。

拖拽后会同步刷新：

1. 原图裁剪框显示
2. 当前裁剪预览
3. 最终拼接预览
4. 右侧边界输入框

## 手动输入边界

用户可以直接输入：

1. 左边界
2. 上边界
3. 右边界
4. 下边界

输入后会把当前图片的裁剪框更新为新的边界值。

## 键盘微调

### 选边规则

1. 点击左、上、右、下任一边后，该边进入高亮选中状态。
2. 点击另一条边时，选中状态切换到新边。
3. 点击图片其他区域后，当前选边状态取消。

### 响应规则

1. 选中左边或右边后，只响应 `←` 和 `→`
2. 选中上边或下边后，只响应 `↑` 和 `↓`

### 步长规则

1. 普通方向键每次微调 `1 px`
2. `Shift + 方向键` 每次微调 `5 px`

### 持续选中

当前选中的边不会在每次微调后自动取消，因此可以连续多次调整同一条边。

## 选中状态何时清空

以下场景会清空当前选边状态：

1. 点击图片其他区域
2. 切换到另一张图片
3. 清除手动修正
4. 新建项目
5. 打开项目
6. 重新批量处理
