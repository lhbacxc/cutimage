# CutImage

CutImage 是一个本地桌面工具，用于批量识别、裁剪并拼接一组比色皿图片。

项目当前基于 `Tkinter + OpenCV + Pillow + NumPy` 实现，支持自动识别主体区域，也支持人工微调裁剪框，并生成统一样式的最终拼接图。

## 主要功能

- 批量读取图片并自动识别裁剪区域
- 支持拖拽裁剪框、手动输入边界、键盘微调边框
- 支持调整图片顺序并恢复自动排序
- 支持黑白背景、细灰边线、圆角矩形
- 支持顶部对齐、居中对齐、底部对齐、上下对齐（拉伸）
- 支持导出最终拼接图，并可选导出 `cropped/` 裁剪图目录
- 支持保存项目并在之后重新打开继续编辑
- 支持中文路径、中文文件名、中文项目文件

## 启动方式

推荐直接双击：

- `./run_cutimage.bat`

当前启动器会调用 Conda 环境中的 `pythonw.exe` 直接启动 GUI，不会长期保留额外的命令行窗口。

程序入口文件为：

- `./app.py`

## 基本使用流程

1. 新建项目或打开已有项目。
2. 选择图片来源并执行“批量处理”。
3. 在界面中检查每张图片的裁剪结果，必要时手动微调。
4. 设置背景、对齐方式、圆角和导出名称等参数。
5. 保存项目，或直接导出最终拼接图。

## 导出说明

- 最终拼接图导出为无损 `png`
- 最终图默认以项目名命名，也支持自定义名称
- 同名最终图采用增量命名，默认不会覆盖旧文件
- `cropped/` 是否导出可在界面顶部勾选控制
